Экспорт библиотек по стилям

Экспорт: отмеченные галочками шаблоны, или вся библиотека (если ничего не отмечено) с учётом фильтров стиля/категории/★. При раздельном экспорте шаблоны автоматически разбиваются по стилям — каждый файл содержит весь стиль целиком из текущей выборки.
src у картинок сбрасывается в "", isFavorite сохраняется, visualStyle проставляется явно. По умолчанию ID остаются как есть.
