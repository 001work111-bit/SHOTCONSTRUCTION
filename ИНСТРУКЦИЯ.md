# Как запустить программу (для тех, кто не программист)

Команды вводить не нужно — всё делается мышкой. Займёт 5–10 минут,
большая часть времени — установка, и только один раз.

---

## Что понадобится

- Компьютер: Windows, macOS или Linux
- Интернет (один раз, скачается ~150 МБ)
- Эта папка с программой

---

## Шаг 1. Распакуйте папку с программой

- **Windows:** правый клик на архиве → «Извлечь всё» → выберите, например,
  Рабочий стол. Путь лучше без русских букв и пробелов.
- **macOS:** двойной клик по архиву.
- **Linux:** `unzip shotconstruction-source.zip`

---

## Шаг 2. Установите Node.js (один раз в жизни)

Node.js — это «движок», на котором работает программа. Бесплатный,
ставится как обычная программа:

1. Откройте сайт **https://nodejs.org**
2. Нажмите большую кнопку **LTS** (не «Current») — начнётся скачивание.
3. Запустите скачанный файл и нажимайте **Далее → Далее → Готово**.
   Никакие галочки и настройки менять не нужно.
4. Готово, компьютер перезагружать не надо.

---

## Шаг 3. Запустите программу

В папке с программой найдите файл запуска и сделайте по нему **двойной клик**:

| Система | Файл |
|---|---|
| Windows | **`ЗАПУСК.bat`** |
| macOS | **`ЗАПУСК.command`** |
| Linux | **`ЗАПУСК.sh`** |

**macOS:** если напишет «файл загружен из интернета» — правый клик → «Открыть»
→ «Открыть» ещё раз.

**Linux:** если файл не запускается — правый клик → Свойства → Права →
поставить галочку «Разрешить запуск как программы».

**Что произойдёт:** откроется чёрное окно с надписями по-русски (надписи печатает
сама программа, поэтому русские буквы всегда отображаются правильно). Окно само:

1. `[ШАГ 1 из 3]` проверит Node.js. Если не найдёт — напишет, что делать.
2. `[ШАГ 2 из 3]` установит компоненты. **2–5 минут.** Окно может выглядеть
   «зависшим» — это нормально, не закрывайте его.
3. `[ШАГ 3 из 3]` соберёт программу. Несколько секунд.
4. Откроется окно самой программы.

При следующих запусках шаги 2 и 3 пропускаются — программа откроется сразу.

### Есть ещё более простой способ: START.bat

Раз вы всё уже установили и запустили — пользуйтесь файлом **`START.bat`**
(на macOS — `START.command`, на Linux — `START.sh`).

Двойной клик → и сразу открывается программа. Никаких сообщений и проверок,
только строка «Запускаю программу...».

> `START.bat` умеет и «починить» ситуацию: если компоненты или сборка
> почему-то пропали, он сам их доустановит и предупредит об этом.
> А если не установлен Node.js — попросит запустить `ЗАПУСК.bat`.

## Шаг 4. Как пользоваться

1. Нажмите зелёную кнопку **«Загрузить папку»** слева и выберите папку
   с картинками. Подпапки внутри станут категориями.
   Рядом есть кнопка **«Демо»** — она открывает встроенный набор картинок.
   Удобно, если свои файлы пока не под рукой: всё сразу работает.
2. Нажмите **Randomize** — программа подберёт случайные картинки во все блоки.
3. Кликните по блоку мышкой — справа появится панель управления:
   замок (чтобы блок не менялся), звёздочка (избранное), затемнение, размер.
4. Вкладки слева: **Blocks** — блоки, **Images** — откуда брать картинки,
   **Text** — надписи, **Overlay** — затемнение, **Stacks** — сохранённые
   комбинации, **Preview** — настройки просмотра, **Settings** — настройки.
5. Зелёная кнопка **Preview** — просмотр на весь экран. Открывается с того
   блока, который выделен. Выход — кнопка **Выход** или клавиша **Esc**.

### Панель «Images»: как работать с картинками

- Слева список папок с количеством картинок в каждой. **«Все папки»** —
  все картинки сразу; выбор одной папки показывает только её.
- У каждой картинки в сетке есть номер — это её индекс внутри выбранной
  папки (или общий, если выбраны все папки).
- **Один клик** по картинке — назначить её в выделенный блок.
- **Двойной клик** (или звёздочка на картинке) — отправить в избранное.
- Галочки «только показываемые / только отсутствующие / только избранное» —
  быстрые фильтры.
- Кнопка **«Экспорт ★»** — копирует все избранные картинки в выбранную вами
  папку, сохраняя структуру подпапок.

### Панель «Preview»: настройки просмотра

- **Переход:** Fade, Slide ↓, Slide →, Cross (перекрёстное растворение),
  Zoom. Можно выбрать мышкой или клавишами **1–5**.
- **Длительность** и **Задержка** (пауза между слайдами при автоплее).
- **Плавность (easing):** ease, in-out, out, linear, soft.
- **Кадр:** «на весь экран» или точный кадр блока (например 1024×768).
- Галочки: полоса прогресса автоплея, кубик в превью, автоплей, по кругу.
- **Режим смены картинок:** «Случайно» (кубик) или «По порядку».

### Режим «По порядку» (без повторов)

Включите его на вкладке **Preview**. Тогда клавиши **Alt+← / Alt+→**
(и такие же в обычном режиме) листают картинки блока по очереди:
сначала все подряд, без повторов, а когда круг закончится — начнётся заново.

### Горячие клавиши

| Клавиша | Что делает |
|---|---|
| **P** | войти в превю / выйти из него |
| **← →** | в превью: предыдущий / следующий блок |
| **Alt+← →** | предыдущая / следующая картинка блока (по порядку) |
| **Space** | пауза / продолжение автоплея в превю |
| **1–5** | выбор перехода (Fade, Slide ↓, Slide →, Cross, Zoom) |
| **F** | текущая картинка в избранное |
| **R** | следующая (случайная) картинка для блока |
| **L** | замок на блоке |
| **Esc** | выйти из превю |
| **Ctrl+Z / Ctrl+Y** | отменить / повторить |
| **Ctrl+S** | сохранить проект |

Всё, что вы делаете, сохраняется автоматически — можно спокойно закрыть
и открыть программу снова, работа продолжится.

## Шаг 5. Как закрыть

Закройте окно программы. Чёрное окно с надписями закроется вместе с ним
(или нажмите в нём любую клавишу).

---

## Если что-то не так

| Что вы видите | Что делать |
|---|---|
| Чёрное окно мигнуло и закрылось | Не установлен Node.js — вернитесь к шагу 2 |
| В чёрном окне красный текст `npm error` | Покажите это окно тому, кто делал программу |
| Программа открылась, но всё серое | Не загружена папка с картинками — нажмите **Load image folder** |
| Белое окно вместо программы | Запустите `ЗАПУСК.bat` заново — он достроит недостающее |
| «Повреждённый файл» на macOS | Правый клик → «Открыть» (см. шаг 3) |
| В окне красный текст `'vite' is not recognized` | У вас **старая** версия файла запуска. Скачайте папку заново и запустите снова |
| В окне кракозябры вместо русских букв | То же самое — нужен новый `ЗАПУСК.bat` |
| Хочу просто запускать программу кликом | Пользуйтесь **`START.bat`** — он запускает сразу, без вопросов |
| Уже запускал раньше и видел ошибку | Ничего удалять не надо: новая версия сама доустановит недостающее |
| Программа просит выбрать папку каждый раз | Так и задумано: браузер не даёт запомнить папку, десктопная версия помнит |
