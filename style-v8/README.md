# Covers Sandbox · редактор стилей v8

**Готовый автономный файл:** `../Sandbox_Styles_v8_WORKING.html`. Скачайте его и откройте в Chrome/Edge. Если библиотека ещё пуста, загрузите `uploads/portfolio_template_library_all_96.js` через **Импорт .js** (97 шаблонов). Папка `style-v8` — исходники и тесты; для обычной работы не требуется.

## Выбор текста, перенос оформления

В **Карте** обычный клик выбирает шаблон, Ctrl/Shift+клик — несколько шаблонов, двойной клик открывает **Один**. Для выбора *текстового слоя* используйте **Alt+клик**; **Alt+Ctrl/Shift+клик** добавляет слои, в том числе из других карточек. Для выбора текстов не нужна кнопка «Начать».

В панели **Стили → Привязки и текст** (под глобальными цветами и шрифтами) выберите **один** текст-источник и нажмите **Скопировать**. Затем выберите один или несколько целевых текстов и нажмите стоящую рядом кнопку **Применить**. Работает с текстами из разных шаблонов, без ручной сессии или внутри неё; действие отменяется через Undo. Копируются *назначенный редакторский стиль, категория, роль, конкретный вариант, цвет и вес*. Содержимое, исходная роль самого блока, font-family, кегль, расположение/геометрия и программный стиль шаблона не меняются. Для копирования исходный текст должен быть привязан к сохранённому варианту; иначе сначала назначьте ему пресет.

В **Все категории** у каждой роли одна горизонтальная строка номеров. Одинаковые *фактический цвет + вес* показываются под одним номером, при этом все категории-источники и конкретные пресеты остаются в данных. Номер записывается **отдельно в привязку каждого текста**. Если выбран один текст, нажатие номера меняет только его; если несколько — только выбранные привязанные тексты этой роли (в «Все категории» — также через разные категории). Работает и без «Начать», с Undo. Без выбранного текста номер лишь выбирается в панели. Непривязанный текст номер сам по себе не назначает: используйте стрелку после «Начать» либо «Скопировать → Применить». Явный выбор номера помечает привязку ручной, поэтому «Авто» и «Варианты» его не перезаписывают. Чтобы изменить цвет/вес конкретного пресета, выберите **Источник** в деталях номера и нажмите **Редактировать в категории ↗**: правка создаёт отдельный live-черновик «+» только для выделенных текстов; у остальных остаётся их номер. Alt+номер удаляет объединённый вариант из всех его исходных категорий с переназначением существующих привязок; в просмотре отдельной категории Alt+номер удаляет лишь вариант этой категории.

**Авто** и **Варианты** доступны и без «Начать», и в ручной сессии; если есть незавершённый черновик пресета, он сбрасывается перед автоматическим действием. **Начать → назначение стрелками → Применить** сохраняет правки шаблонов; нижняя кнопка **Применить** завершает *сессию*, в отличие от кнопки переноса в блоке привязок. **Отменить** возвращает текстовые правки шаблонов, но сохраняет созданные пресеты, настройки стиля и независимо изменённые картинки. При действиях панель не сбрасывает прокрутку наверх.

## Картинки

Нажмите **🖼** в верхней панели: откроется библиотека изображений. **＋ Загрузить** добавляет файлы, **📁 Папка** рекурсивно добавляет поддерживаемые изображения из папки и подпапок. Можно также перетащить файлы в окно. Загрузка не зависит от «Начать». Изображения хранятся в IndexedDB браузера, а шаблоны содержат короткие ссылки вместо многократно продублированных base64-файлов.

**🎲 Все** обновляет *все* шаблоны библиотеки, независимо от выделения, фильтров и ручной сессии. **🎲 1** обновляет только один выделенный шаблон (или активный, если ничего не отмечено); при множественном выделении попросит выбрать один. Кубик на изображении в режиме **Один** также обновляет все image-блоки только этого шаблона. Картинки, изменённые во время «Начать», сохраняются и после **Отменить**. Оформление текста от случайной смены изображений не меняется.

**Важно для переноса:** пул изображений хранится локально в браузере; сам HTML и существующий JSON-архив не включают бинарные файлы из IndexedDB. Для работы на другом компьютере сохраняйте исходную папку изображений и загрузите её заново. В ограниченном предпросмотре файла хранилище браузера может быть недоступно: тогда изображения работают только до закрытия вкладки; для постоянной работы открывайте скачанный HTML непосредственно в браузере.

## Независимые стили

`template.visualStyle` — программный стиль (фильтры и библиотека), `template.editorStyleId` — набор пресетов редактора; привязки лежат в `template.v5Bindings`. **Применить** в редакторе никогда не переносит шаблон в другой программный стиль. Для копирования самих шаблонов выделите их в обычной библиотеке и нажмите **⧉ В новый стиль** в действиях/инспекторе; оригиналы остаются на месте. Исторические стили v5/v6, категория и привязки мигрируют при открытии этой версии; архивы предыдущих версий поддерживаются.
